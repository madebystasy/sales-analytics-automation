# Автоматический Excel-отчёт по продажам

Автоматизация аналитики продаж: генерация Excel-отчёта с метриками, топами продуктов и дашбордом.

## 📊 О проекте

Скрипт на Python читает CSV-файл с данными о продажах и автоматически создаёт:

- Excel-отчёт с 3 листами (Данные, Сводка, Топ продуктов)
- Форматированные метрики (выручка, средний чек, количество продаж)
- Дашборд с динамикой по месяцам
- Анализ по регионам и категориям


- Python 3.11
- Pandas — обработка данных
- OpenPyXL — генерация Excel


## Структура данных (sales.csv)

| Колонка | Описание |
|---------|----------|
| date | Дата продажи |
| product | Наименование товара |
| price | Цена за единицу |
| quantity | Количество |
| revenue | Выручка |
| category | Категория товара |
| region | Регион продажи |
| customer_type | Тип клиента (физ/юридическое лицо) |
| returned | Флаг возврата |


1. Установите зависимости:
pip install pandas openpyxl

2. Подготовьте файл sales.csv в той же папке

3. Запустите скрипт:
python report_generator.py
4. Откройте weekly_report.xlsx
